# MCP `2026-07-28` protocol spine (Phase B)

**Status:** Implemented on `feat/video-editor-module` (and ported to main worktree `feat/mcp-2026-07-28`)  
**Date:** 2026-08-06

## What shipped (Phase B)

- `server/discover` with `resultType`, `supportedVersions`, tools capability, `serverInfo`
- Dual-mode default: legacy `initialize` still works; 2026 clients use `_meta`
- Strict mode (`--mcp-protocol strict`): no initialize; required `_meta` + `Mcp-Method`
- `tools/list` / `tools/call` wrap `resultType: "complete"`
- Header validation when `Mcp-Method` / `Mcp-Name` present (required in strict)
- Body size limit 8 MiB
- Auto session token write when `--mcp-secret` omitted
